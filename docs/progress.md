# RagsGO 진행 상황

마지막 갱신: 2026-11-20

대화 맥락(사용자 말, 답, 결과)은 `docs/context-log.md`에 매 응답마다 적는다.

## 지금 상태

- **Phase 1-b 완료** (2026-11-18). 띵바츄 1곡, 임시 정답 기준으로 넘김이 모두 맞았다. Phase 1 판정(원곡 3곡)은 원곡 파일을 기다린다.
- **앱 설계 초안 완료** (2026-11-19). 자동 넘김은 기록 모드 → 예측 모드 → 자동 넘김 순서로 켠다.
- **첫 구현은 M2(기록 모드)로 정했다** (2026-11-19, 사용자). 다음 합주까지 시간 여유가 있다.
- **플랫폼: 웹 제안 철회, 네이티브 유지** (2026-11-20). 사용자 지적: 인터넷이 필요 없는 앱이고 반응성이 중요하다 (U18). 악보는 아이패드로 보므로(U17) 아이패드 화면(Swift)을 먼저 만드는 것을 제안했다. 엔진(C++)은 공통이다 (앱 설계 16.7절). 사용자 결정 대기.
- 이 맥은 애플 실리콘이라 아이패드 앱을 기기 없이 이 맥에서 시험할 수 있다. 아이패드는 합주 때 1대만 있으면 된다.
- 맥 디스크 여유 4.9 GB (11/20). 기기를 처음 연결하면 수 GB가 더 들 수 있다. 그 전에 정리 여부를 묻는다. 삭제는 사용자가 고른 것만 한다.

## 사용자에게 남은 것

- 첫 구현 기기 결정 (위 1번)
- 아이패드면: 합주에 쓸 아이패드 1대 (본인 것 또는 멤버 것, 합주 주에 이 맥에 USB로 한 번 연결), 개인 프로젝트에 쓸 Apple 계정
- 띵바츄 클릭 확인 (`exp/check/tac_check.html`, 약 5분). Phase 1-b 수치가 이것으로 확정된다.
- 원곡 파일: 1:03과, 하늘을달리다·파도·원피스·Ready get set 중 1곡 이상. 다음 합주에서 칠 곡의 원곡이면 더 좋다.
- 다음 합주에서 칠 곡 목록과 자기 파트 PDF
- 늦게 넘김 허용 1박 확정
