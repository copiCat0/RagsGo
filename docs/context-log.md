## 작업 규칙 (사용자가 정한 것)

- 질문은 한 번에 하나, 객관식. 제품 정의로 답이 정해지는 것은 묻지 않고 기본값으로 간다.
- 보고는 짧고 쉬운 한국어로, 결론 먼저, 비유 없이.
- 단계 전환(실험, 구현 착수)은 사용자 지시로만 한다.
- 로컬 환경 변경(빌드, 설치)은 미리 승인받는다. 삭제는 사용자가 고른 것만 한다. 외부 공개와 호스팅도 승인받는다.
- 자동 실행(launchd, cron, 훅, 워처)은 쓰지 않는다.
- 원곡에서 나온 소리는 `exp/data/` 안에만 두고 밖으로 보내지 않는다.
- 별도 장비나 특수 배치를 선택지로 내지 않는다.
- 셸 명령은 절대경로로 쓴다. git 커밋은 하지 않는다.
- 녹음처럼 사용자 손이 가는 것을 부탁할 때는 이유를 같이 말한다.
